ARC Tower · Azure Platform Connector

How one product's Azure resources are found inside a resource group shared by several products, and how their metrics, cost, risks and traces reach ARC Tower

What the user gives

  • • Subscription ID(s) and one starting point (the product's app)
  • • Read-only credentials once (none with Managed Identity / Lighthouse)
  • • Resource group and product tag are optional
  • • Then only Yes / No on the proposed map, plus a share % for shared resources

How one product is isolated

  • • Follow the starting point's managed identity to every resource it was granted
  • • Add hosting, App Insights, tag, network and name evidence, then score it
  • • Resources only other products' identities use are never linked or pulled
  • • Shared resources are flagged; their cost is split by the reviewer's share %

What flows into ARC Tower

  • • Metrics: latest 1-minute values per mapped resource (Azure lags 1-3 min)
  • • Cost: month-to-date per resource every hour, attributed to the product
  • • Risks: public access, key-based auth, anonymous blobs, missing tags
  • • Traces: only when the app sends to App Insights / OpenTelemetry
